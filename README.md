One sentence, 148 characters, explaining the modern internet to a time traveler from 1800 — "Every door on earth now opens onto every other door, so you may speak with any soul alive and read any book ever written without leaving your chair." A single comparison, true of the internet as it is: distance gone, talk two-way, every book at hand, in words a person from 1800 already knows. This program writes that one sentence to /output/entry.txt; a house judge compares the sentences two at a time, and the best win rate takes the prize.

## Run it

```sh
python3 main.py
```
